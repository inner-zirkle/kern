---
title: "CRDTs over consensus"
---

## Decision

Where two views of one store have to be reconciled, they converge through
per-field merge operations that commute — no leader, no lock, no consensus
protocol.

## Why

kern is local memory and single-writer, so this is not about distribution. It is
about the one case where a daemon meets state it did not write: LMDB is
single-writer, a flush can be refused as stale, and an external commit has
landed underneath an in-memory snapshot that still holds unflushed rows.

- Commutative, associative, idempotent merges make that reconcile *retryable* —
  it does not matter which side wrote last, or how many times the fold runs.
- Plain last-writer-wins loses data here: the snapshot's unflushed rows and the
  committed rows are both real, and clobbering either is a silent loss.

Per-field joins:

| Field | Join |
| --- | --- |
| access / traversal counters | G-Counter: per-replica slot, merge = pointwise max, value = sum |
| `created_at` | min (earliest observation wins) |
| `accessed_at`, `updated_at` | max |
| edge score, `valid_until` | LWW on `(lamport, producer)` — never wall clock |
| `status` | monotone toward `Superseded`, never back |

Load-bearing detail: LWW ties break on `(lamport, producer)`, so clock skew
cannot lose an update.

## Rejected

| Alternative | Why it lost |
| --- | --- |
| Refuse the flush and drop the snapshot | the unflushed rows are real writes a caller was already acked for |
| Overwrite the store with the snapshot | discards the external writer's commit — the defect this exists to prevent |
| Wall-clock LWW everywhere | two concurrent `+1`s must sum to `+2` but LWW keeps one; clock skew makes "last" a lie |

## Trade-off accepted

- Confidence never merges — `conf_alpha`/`conf_beta` are exempt; a max-join on
  belief is an irreversible pin, and evidence is counted where it was observed.
- Statements never merge — an entity's id is the content hash of its text, so a
  differing body asserts text its id does not hash to.
- CRDT semantics enforced by hand at call sites, not by typed registers.
- Convergence of state, not truth — two contradicting facts both survive;
  adjudication belongs to supersession, not a merge thread.

<Callout type="info" title="No network is involved">
These joins never cross a machine boundary. kern has no peer protocol and no
remote writer — see [Security](../concepts/security.mdx).
</Callout>
