# Project document index

Generated by `/index`. It inventories tracked documentation plus untracked Markdown in the repository, excluding generated/vendor/history trees: `.git`, `node_modules`, `.worktrees`, `.splinter`, `.kern`, `_archive`, `dist`, `coverage`, `.cache`. Binary files are not read; hidden Markdown is included unless inside an excluded tree.

## Canonical roles

- `docs/prd.md`: current product record; `docs/specs/`: contracts; `docs/plans/`: unlanded plans; `docs/analysis/`: frozen evidence.
- `.pi/gantt/`: live execution map and tickets; root/package READMEs and agent instructions remain local.
- Other documents require a reviewed destination; filename heuristics are proposals, not authority.

## Apply protocol

Default `/index` is dry-run only. Review `.pi/index-plan.json`, resolve all conflicts, then run `/index --apply .pi/index-plan.json --yes`. Apply requires a clean Git tree; it validates destinations and references, copies/moves only after validation, verifies no reference still targets a removed path, and rolls back changed paths on failure. It never creates symlinks or redirect stubs.
